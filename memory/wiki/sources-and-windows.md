# Sources and windows

Facts about the evidence behind our decks.

## Standing rules

- One deck, one window. Label it on every slide with numbers: "12 months ending <date>", or the true span if the source holds less.
- A percentage shows its base on the same slide.
- A number from outside the named sources is labeled external, with where it came from.
- Rows with no source do not go on a slide.
