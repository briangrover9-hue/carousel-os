# Deck decisions

Standing decisions about how we build decks, each with its reason. Change one only on purpose and say why.

| Decision | Reason |
|---|---|
| The human starts every stage. | A stage that starts the next one cannot be stopped between the two. |
| Three critique rounds on the full path, one on the short run. | Three rounds with different angles catch what one reader misses. The short run trades depth for time and says so. |
| The brief is the only interview. | Later stages run without the human, so open questions need to be settled once, early. |
| The review runs in a fresh context. | The builder cannot see their own blind spots. |
| The theme is a plain, restylable default. | Examples need something neutral to stand on. Real decks bring their own look. |
