# Bookshelf

Reference pages the stages read. A stage names the page it needs, so nothing here is loaded all at once.

## Process pages

- [ask-first.md](ask-first.md): the brief's questions in order, and the conservative default each later stage uses.
- [lessons.md](lessons.md): how corrections become lessons, then rules, and who decides.
- [claim-ledger.md](claim-ledger.md): the ledger's fields, the rule for `checked`, and the final gate.
- [review-angles.md](review-angles.md): the master list of critique angles for decks.
- [engine-contract.md](engine-contract.md): the config file and exit codes for plugging in your own engine.

## Craft pages

- [rubric.md](rubric.md): the review dimensions, floors, caps, and what P0 and P1 mean.
- [preflight.md](preflight.md): the checklist by section and the list of anti-tells.
- [design.md](design.md): the taste layer behind what gets drawn.
- [writing.md](writing.md): the writing standard for slide text.
- [narrative-devices.md](narrative-devices.md): named slide beats for the storyboard.
